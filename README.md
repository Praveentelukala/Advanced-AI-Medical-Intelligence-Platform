# Advanced-AI-Medical-Intelligence-Platform

## Overview
Advanced AI Medical Intelligence Platform is an AI-powered web application for brain MRI tumor detection. It uses Deep Learning, Explainable AI (Grad-CAM), and Google Gemini to analyze MRI scans, explain predictions, and generate AI-assisted medical reports.

## Features
- Brain MRI Tumor Classification
- EfficientNetB0 Deep Learning Model
- Explainable AI using Grad-CAM
- AI Medical Report Generation using Google Gemini
- FastAPI REST API
- Streamlit Web Interface
- Prediction Confidence Scores
- Heatmap Visualization
- Modular Project Architecture
- Cloud Deployment
